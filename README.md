# karen-in-europe
STAT 306, Fall 2026 activity to reproduce "You Know Karen" analysis for UK Babynames 

Before you start your assigned issue be sure you have completed the karen-training.qmd assignment.

After you have made a new R project based on this repository, add your `full-names-data-nice.csv` from the karen-training to this directory. You will not push this dataset (.csv files are added to the .gitignore), but you will want to read it in from this folder rather than your training folder.

You will want to make use of the helper functions. You can read these in to your file with:

`source("karen-helper-fns.R")`


Put your solution in a file that is either called your-name.R or your-name.qmd
